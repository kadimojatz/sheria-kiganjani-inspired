# Haki Legal bilingual consultation platform

## What I’ll build
- Replace the blank page with the selected “Frosted dossier” visual direction: calm legal authority, cool paper surfaces, teal trust cues, and coral urgent actions.
- Add a responsive header with brand, navigation, English/Kiswahili toggle, mobile menu, and WhatsApp contact.
- Build the full home experience: legal-help introduction, verified statistics, four consultation services, advocate search and filters, bilingual Q&A, client testimonials, trust details, office hours, and contact information.
- Add realistic advocate profiles with accreditation, experience, ratings, languages, locations, and TZS/USD consultation rates.
- Implement an interactive booking dialog with four steps: consultation channel, date/time, case summary, and simulated M-Pesa/Tigo Pesa/Airtel Money/card payment selection.
- Make all visible content switch between English and Kiswahili, including navigation, filters, booking, Q&A, trust copy, and feedback states.

## Interaction details
- Directory search will match advocate name, specialty, and location; filters will cover field, location, and language.
- Q&A entries will be searchable and expandable with plain-language answers.
- Booking can start from the main action or an advocate card, preserves the selected advocate, validates required fields, and ends with a clear simulated confirmation.
- WhatsApp actions will open a prepared message in a new tab.

## Technical details
- Keep this as a focused front-end prototype with local sample data and simulated payment; no accounts, database, or real payment processing.
- Use semantic design tokens in the global stylesheet and the selected Archivo, Inter, and JetBrains Mono typography.
- Use accessible labels, keyboard-friendly dialogs/accordions, reduced-motion support, and layouts verified at desktop and mobile widths.
- Add route-specific title, description, Open Graph, and Twitter metadata.
